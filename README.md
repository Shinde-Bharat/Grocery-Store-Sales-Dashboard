# 🛒 Grocery Store Sales Analytics Dashboard

## 📌 Project Overview
This mini-project focuses on analyzing grocery store sales data using Microsoft Power BI. The dashboard provides interactive visualizations to understand sales performance, identify top-selling sub-categories, analyze monthly sales trends, and compare sales across different regions.

## 🎯 Objectives
- Analyze overall grocery store sales performance.
- Identify top-selling product sub-categories.
- Visualize monthly sales trends.
- Compare sales performance across regions.
- Provide interactive filtering for better analysis.

## 🛠️ Tools & Technologies
- **Microsoft Power BI Desktop**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Kaggle Dataset** – Supermart Grocery Sales – Retail Analytics Dataset

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Average Sales per Order

### 2. Top-Selling Items
A bar chart displaying sales performance across different product sub-categories.

### 3. Monthly Sales Trend
A line chart showing sales trends over time.

### 4. Sales by Region
A column chart comparing sales across different geographical regions.

### 5. Interactive Filters
- Region
- Category
- Order Date

## 📂 Dataset
**Dataset Name:** Supermart Grocery Sales – Retail Analytics Dataset

Source: [Kaggle – Supermart Grocery Sales](https://www.kaggle.com/datasets)

The dataset contains grocery sales information such as order dates, product categories, sub-categories, cities, regions, and sales values.

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Grocery_Store_Sales_Dashboard.pbix`.
4. If required, update the dataset file path.
5. Refresh the data and explore the dashboard.
